# Xclip：並行して進める3方針（2026-10-06）

ユーザー決定：下記は優先順位ではなく並行する。今日は3のTier評価改善を進める。

## 1. 流入確保

X、アンテナサイト、紹介記事で紹介する。仮説：Xは初期の小規模な効果測定、紹介サイトは関心の近い閲覧者を継続的に送り込む入口になり得る。掲載依頼を準備し、投稿・掲載先ごとのリンク識別と、来訪→動画OPEN→5秒視聴→再訪で判断する。自然な紹介投稿と宣伝は区別し、紹介数だけで成功と判断しない。メール・フォームの送信は今回実施しない。

## 2. 動画保存機能

類似サイトの一般的な機能に合わせ、まず掲載済み動画の端末への保存を検討する。サイト内お気に入りは別機能として区別する。仮説：端末保存は利用目的と紹介しやすさ、サイト内保存は再訪に寄与する。既存動画URLを使いX API追加取得を避ける構成を優先し、スマホでの保存動作、保存成功/失敗、期限切れURL、動画配信の通信量を検証する。汎用の投稿URL取得サービスへの拡張は別途判断。今回コード追加はしていない。

## 3. Tier評価アルゴリズム

手動教師評価に自動評価を近づける。現在の収集補正はDB manual_tierのみを使い、参考アカウント教師レビューの通常の評価はローカルdata/teacher-authors.jsonに保存される。既存視覚モデルはdata/visual-preference-model.jsonと視覚特徴キャッシュを使用する別経路。教師データの統合と実データでの精度確認が必要。

本日の実装：/tier-teacher-analysis をローカル管理画面に追加。DB手動評価とローカル教師評価を投稿IDで照合し、重複はDB手動評価を優先する。安全除外や不正データは使わない。キャッシュ済み視覚特徴で分散を正則化したクラス代表特徴を学習し、投稿者と完全一致特徴を学習/検証へまたがらせない比較を行う。

S/A/OTHER/Xの分類を測る。B/C/Dは教師画面のOTHERと粒度を揃えるため比較上OTHERにまとめる。B/C/Dを個別に正しく判定できることの検証ではない。現行比較欄はメタデータ学習部でありルール混合後の最終Tierとは異なる。総合一致率、クラス平均F1、S/A適合率・再現率、同じ比較対象での両方式の値を見る。教師モデルの順位ペア精度とは別の指標。

現段階ではDB・本番アルゴリズム・X収集を変更しない。実PCの教師データ・特徴キャッシュにアクセスできないため実精度は未測定。次は診断結果を確認し、未抽出データの準備、より適した学習・閾値の検証、再評価画面への接続、最後にColorfulBox収集への反映を行う。検証に繰り返し使用したデータは最終評価用から外す。
