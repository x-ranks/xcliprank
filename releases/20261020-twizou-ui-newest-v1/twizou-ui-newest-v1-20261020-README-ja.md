## 適用

本番サーバーへ `twizou-ui-newest-v1-20261020.sh` だけをアップロードし、以下を順に実行します。シェルファイルには検証済みの更新一式が埋め込まれています。

```bash
bash /home/rbxfxmfd/twizou-ui-newest-v1-20261020.sh --check
bash /home/rbxfxmfd/twizou-ui-newest-v1-20261020.sh --apply
```

`CURRENT_SOURCE_AND_UI_NEWEST_PAYLOAD_HASHES_MATCH` と `PRECHECK_OK` が事前確認の成功表示です。適用成功時は `TWIZOU_UI_NEWEST_V1_DEPLOYMENT_COMPLETE`、`PREVIOUS_RUNTIME_BACKUP=...`、`NEW_BUILD_ID=...` が出ます。失敗した場合は、公開runtimeを以前のものへ自動で戻します。`SOURCE_CHANGED_...` 等が出た場合は、本番ソースが想定と違うため更新を止めます。

ローカルはZIPを展開し、開発サーバーを停止してからPowerShellで次を実行します。

```powershell
node .\apply-local.cjs --check
node .\apply-local.cjs --apply
```

成功時は `LOCAL_SYNC_APPLIED files=7 backup=...` が出ます。戻す場合は、表示されたバックアップ先を指定して `node .\apply-local.cjs --rollback "バックアップ先"` を実行します。ローカルのランキングAPIは本番の版を読む既存方式を維持します。
