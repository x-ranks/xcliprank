# 動画50件で新Tierを確認

この追加は、手動Tierだけで学習した未採用モデルを実際の動画で試すローカル画面です。DBのpostsのTier、手動評価、本番ランキングを変更しません。表示するモデルと現在のTierはプレビュー作成時に固定します。

## PCでの手順

1. 開発サーバーをCtrl+Cで停止する。
2. ダウンロードしたインストーラーを実行する。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\xclip-tier-video-preview-20261008.ps1" -Project "C:\Projects\xcliprank"
```

3. 同じPowerShellで次の順に実行する。

```powershell
cd C:\Projects\xcliprank
$env:XCLIP_FFMPEG_PATH = "C:\Projects\xcliprank\.local-admin\ffmpeg\ffmpeg.exe"
$env:XCLIP_FFPROBE_PATH = "C:\Projects\xcliprank\.local-admin\ffmpeg\ffprobe.exe"
npm run dev -- --hostname 127.0.0.1 -p 3004
```

4. http://localhost:3004/tier-personal-model を開き「保存済み特徴で2方式を比較（動画取得なし）」を押す。検証完了まで画面を開いて待つ。この再計算でプレビュー用手動モデルも保存される。
5. http://localhost:3004/learning-tools#operations の「新Tierモデル・動画50件プレビュー」を開く。直接のURLは http://localhost:3004/tier-video-preview 。
6. 「ランダム50件のお試し比較を作成」を押す。最大150件を試し、成功50件で停止する。特徴がある動画は再取得せず、ない動画は4フレームを抽出する。準備できた動画から順に表示する。50件集まらない場合は取得失敗件数を確認する。
7. 変更を見るだけなら「全動画の変更前後を表示」を押す。自分との一致を測る場合は先に動画を見てTierボタンでメモを付ける。予測を見た後や評価を編集した場合、そのメモは一致率の集計から除く。
8. 「確認結果をJSONで保存」で結果を共有する。エクスポートには秘密値・動画URL・モデル重みを含めない。

SQL変更・X API収集・本番デプロイは不要。インストーラーは既存ファイルの互換性を全件検証し、別ブランチとバックアップを作る。運営管理ページはリンクだけを追加する。収集プログラムや通常レビュー画面には触れない。

## 容量超過の教師動画を補充する場合

プレビュー下部の「容量超過の教師10件を再試行」で、手動評価済みで公開・安全条件を満たす容量超過動画だけを10件ずつ再試行する。上限256MiB/動画、10件で最大約2.5GiB。通常抽出の上限96MiBは維持する。成功済み特徴は再取得せず、試行済みIDはPC内に記録して次のバッチから除く。途中停止したバッチは「再試行を続ける」で再開する。

成功件数が増えたら手順4の保存済み特徴の比較を再実行し、検証完了後に新しいプレビューを作成する。既存プレビューのモデルは途中で差し替えない。モデル採用は別の検証が必要で、この画面からは採用できない。

元URLが404等ならHTTPコードを記録する。低容量版URLはDBに保存されていないため、URLを推測したりX APIで取り直したりしない。動画取得には通信量とCPUを使う。

## 見方と制限

- 現在のTier → 手動モデルの提案Tierを動画ごとに表示する。信頼度60％未満では現在のTierを維持し、視覚判定の生のTierも別に表示する。
- 確認メモはPC内の `.local-admin/tier-video-preview` に保存する。本番の手動Tier教師には追加しない。
- 教師に含まれる投稿者／含まれない投稿者を区別し、予測を見る前のメモと未学習投稿者の集計を別に示す。
- ランダム50件を見た体感や同じ検証データの再利用は、独立した精度向上の証明にならない。合格判定・本番適用を自動で行わない。
- 動画が取得できない、対象が少ない場合は50件未満になる。処理時間は動画サイズとPC性能に依存し、当日完了を保証するものではない。
- 画面を閉じると実行中の1件の後に停止する。PCスリープ中は処理しない。開き直して「続きを準備」で続行する。
- サーバーの強制終了後に「別処理が実行中」が残る場合、開発サーバーを完全に停止してから `.local-admin/tier-video-preview/lock` のみ削除して再起動する。preview.jsonやrescue.jsonは再開に必要なので削除しない。

## 開発確認

型検査・Next.jsビルド、実際の4色動画をFFmpegで10/25/50/80％抽出するテスト、上限サイズとHTTP失敗のテスト、模擬DBによる50件停止・安全再確認・Tier無変更・予測後評価の除外・10件再試行のテストを実行する。実DB・Windows実機での動作はインストール後の確認が必要。
