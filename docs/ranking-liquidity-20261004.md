# ランキング配分（2026-10-04）

- 新着: 直近24時間の適格動画を新しい順に最大100件。その後、過去のS/A+/Aから日替わりランダムで50〜100件を追加する。合計100件未満にならないよう、直近動画が少ないほど過去枠を増やす。通常の合計は100〜150件で、初期画面に全件表示する。
- 24時間: 85件の過去枠を従来のTier/品質/人気順で確保する。残り15件は新着に未掲載の直近動画を優先し、不足時は未掲載のS/A+/Aの過去動画で補う。この場合、過去動画の実数は85件を超える。過去85件は予約枠の数。
- 同じ候補スナップショット内では両タブの投稿IDは重複しない。各タブ内も重複しない。
- 日替わりの境界は日本時間0時。両タブ共通の5分単位の候補スナップショットを使う。新しい投稿の反映は通常5分以内。日付やスナップショットが変わる前に開いていたページとは内容が変わり得る。
- 有効な選別投稿者のみ、表示可、要確認/モデレーション除外、コンテンツフィルタ、手動Tierを維持する。NONE等で水増ししない。各タブ1投稿者20件上限を維持。適格候補不足では100件や過去予約枠を保証できず、APIのliquidityに不足数を返す。
- 共有配分キャッシュはプロセス内の最大2スナップショットに制限し、5分ごとに永続キャッシュファイルを増やさない。
- DB候補取得は直近最大1000件、過去最大3000件のページ取得。DB保存済み動画のみを使用し、X API収集を追加しない。
- 週間の配分と収集期限切れ処理は変更しない。Tier/スコア非表示と動画時間表示を保持。

検証: 新着0/10/50/100/160/300件、85件高Tier枠、A以上、100件以上、50〜100件、相互重複0、同日固定・翌日変更、JST境界、候補不足、NONE、重複IDをオフライン検証。
