# B/C境界・S過大評価の調整

今回の50件は対象外Xを除いた48件で、新モデル完全一致11件、低め評価34件、高め評価3件。20件が手動B→モデルCだった。これを開発上の問題発見として、正式な教師データに基づく調整候補を追加する。今回のプレビューメモを教師テーブルに自動追加しない。

## 調整内容

1. **順位学習**：D<C<B<A<Sの順序と4本の境界を学習する累積ロジスティックモデルを追加。手動B/Cを正確な教師として使い、OTHERはA/Sではない情報だけに使う。B・Cの教師がそれぞれ10件未満なら順位候補を保留して不足を表示する。一律のTier引き上げはしない。
2. **S抑制**：S判定にはスコアの下限と他Tierとの差を要求し、条件を満たさない場合は元のTierを維持。S条件0.75/0.85/0.95、全体下限0.45/0.6、温度補正1/1.5/2を調整用データだけで比較する。スコアは実際の正解率ではない。
3. **比較**：従来の手動モデル、手動＋S抑制、手動の順位学習、参考評価統合を同じ教師分割で比較する。選択ではTier完全一致、B/C一致、分類F1、S/A過大評価、低評価→Sを使う。最終検証の数字を見て選び直さない。
4. **動画で確認**：順位学習とS抑制の調整候補から調整用で選んだ手動モデルをプレビュー用に保存する。全体で選んだ候補とプレビューの候補が異なる場合は、画面に双方の名前を表示する。新しい抽出では以前プレビューに用意した動画を除外する。

## PCへ適用

開発サーバーをCtrl+Cで停止し、Downloadsに保存したインストーラーを実行する。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\xclip-tier-ordinal-adjustment-20261008.ps1" -Project "C:\Projects\xcliprank"
cd C:\Projects\xcliprank
$env:XCLIP_FFMPEG_PATH = "C:\Projects\xcliprank\.local-admin\ffmpeg\ffmpeg.exe"
$env:XCLIP_FFPROBE_PATH = "C:\Projects\xcliprank\.local-admin\ffmpeg\ffprobe.exe"
npm run dev -- --hostname 127.0.0.1 -p 3004
```

1. http://localhost:3004/tier-personal-model を開き「保存済み特徴で候補モデルを比較（動画取得なし）」を押す。
2. 検証完了まで画面を開いて待つ。今回は保存済み4フレーム特徴を使うので教師動画の再取得はない。
3. 「比較結果をJSONで保存」する。新候補のB/C一致率、低評価→S率と、プレビュー用の手動候補名を確認できる。
4. http://localhost:3004/tier-video-preview を開いて「ランダム50件のお試し比較を作成」を押す。既存プレビューはPC内に履歴として残る。新プレビューは今回の50件を含めない。
5. 動画を見て、予測を表示する前にTierメモを付ける。互換再生は引き続き利用できる。準備済みの特徴は再利用し、未準備の動画だけ抽出する。
6. 「確認結果をJSONで保存」する。比較結果とプレビュー結果を共有して、実データで改善を確認する。

SQL変更・X API収集・本番デプロイは不要。インストーラーはファイル互換性を検証し、ブランチとバックアップを作る。学習状態と任意の新特徴の保存は既存テーブルで行うが、postsのTierや正式な手動評価は変更しない。互換再生用キャッシュは既存仕様のまま使う。

新しい方式のモデルを自動採用しない。旧モデルはそのまま利用可能。実データの結果と新しい動画による検証を見て、モデル採用と過去動画への反映を別途判断する。

## 比較の限界

既存の調整・最終検証動画も観測済みなので、画面の判定は開発比較である。新しいプレビューも教師に含まれる投稿者がいるため、予測非表示評価と未学習投稿者の集計を区別する。過去の動画を除外しても、未知投稿者の精度を保証するものではない。

今回の変更は見た目の特徴を増やさず、学習する評価の境界と判断条件を改善する。特徴抽出失敗による教師の偏りや4フレームに写らない場面は別の制限として残る。候補が従来方式より良くなる保証はなく、結果が悪ければ採用しない。
